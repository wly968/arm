# 🤖 基于 MuJoCo 与 PPO 的双传送带机械臂视觉伺服系统

> ⚠️ **项目状态**：Phase 1 (动态目标悬停) + Phase 2 (夹爪姿态对准) 已完结，成功率 100%，即将开启 Phase 3 (物理抓取)。

## 📖 项目简介

本项目是一个面向具身智能（Embodied AI）与工业自动化的高保真仿真基准。系统在 MuJoCo 物理引擎中构建了包含 L 型双传送带、6-DoF 机械臂及平行夹爪的动态分拣场景。

当前已完成**前两阶段**的强化学习（PPO）闭环：
*   **Phase 1 (视觉伺服到达)**：机械臂精准追踪并平滑悬停在动态方块上方。
*   **Phase 2 (姿态预抓取)**：在悬停点自动旋转手腕（Tool Roll），实现与方块边缘的绝对平行，并完全张开夹爪，为最终下降抓取做好准备。

## ✨ 核心特性与技术亮点

1. **高精度物理建模 (MJCF)**：自建含摩擦、阻尼及自碰撞过滤的轻量化机器人模型，底座与传送带环境。
2. **多阶段状态机与“无退避”策略**：打通 Phase 1 与 Phase 2 的无缝切换，并在 Phase 2 取消了回退惩罚，彻底解决了强化学习中常见的“惩罚悬崖（Penalty Cliff）”与策略死锁，大幅加快收敛。
3. **渐进式课程学习 (Curriculum Learning)**：动态阈值 Callback，将距离误差从 5cm 逼至 3cm，角度余弦相似度从 0.9 逼至 0.99。
4. **复合动作平滑惩罚**：对连续动作输出加入平方差惩罚，杜绝了机械臂在寻优过程中的“抽搐”现象。
5. **23 维高阶多模态观测**：融合本体感受（关节角、速度、夹爪开合）与外部感知（目标 3D 相对位置、夹爪与方块的二维朝向向量）。
