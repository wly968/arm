# 🤖 基于 MuJoCo 与 PPO 的双传送带动态机械臂抓取系统

> ⚠️ **项目状态：Phase 1 (感知与悬停对准) 已完结，Phase 2 (动态抓取) 开发中...**

## 📖 项目简介

本项目是一个面向具身智能（Embodied AI）与工业视觉伺服的高保真仿真基准。系统在 MuJoCo 物理引擎中搭建了包含双传送带、4自由度机械臂及平行夹爪的工业场景。

当前 **第一阶段（Phase 1）** 已完整实现：通过深度强化学习（PPO）与课程学习（Curriculum Learning），控制机械臂平滑运动至动态目标（传送带上的方块）正上方，并实现夹爪完美垂直对准，最高成功率 100%，平均收敛步数稳定在 32 步左右。

## ✨ 核心特性 (Phase 1)

1. **高精度物理建模**：使用 MJCF 构建含摩擦、阻尼、重力补偿及自碰撞过滤的轻量化机器人模型 (`train_scene.xml`)。
2. **渐进式课程学习 (Curriculum Learning)**：自定义 Callback，在 200 万步训练中分阶段收紧距离（5cm -> 3cm）与角度（0.9 -> 0.99）的成功阈值，逼迫策略逼近物理极限。
3. **多模态状态观测**：融合本体感受（关节角度/速度/夹爪开合度）与外部感知（目标相对位置、方块边缘方向、夹爪长边方向），构建高维 1D 特征向量喂入网络。
4. **平滑控制奖励设计**：引入动作变化惩罚（Action Smoothing），彻底杜绝了机械臂在强化学习初期的“帕金森式”抽搐与过冲。
